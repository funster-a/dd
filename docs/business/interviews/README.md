# Интервью с организаторами

Финмодель держится на допущениях (`docs/business/README.md`), а реальных клиентов у проекта нет. Интервью нужны, чтобы на защите опираться на опыт настоящих организаторов, а не только на оценки. Цель — проверить допущения, не продавать.

## Что здесь

| Файл | Зачем |
|---|---|
| [`guide-smb.md`](guide-smb.md) | Гайд для организатора МСБ: 30–40 минут, вопросы о последнем событии и нынешнем способе продажи |
| [`guide-large.md`](guide-large.md) | Гайд для промоутера или площадки от 2 000 мест: старт продаж, выбор оператора, условия |
| [`assumptions.md`](assumptions.md) | Какое допущение финмодели проверяет какой вопрос и насколько ответ меняет итог |
| [`consent.md`](consent.md) | Согласие на запись и цитаты |
| [`notes-template.md`](notes-template.md) | Шаблон обезличенных заметок |

## Сколько и когда

По умолчанию, пока владелец не решил иначе (`docs/defense/decisions.md`, вопрос 4): **3–5 организаторов МСБ и 1–2 из крупного сегмента до 20.12.2026**.

Воронка с запасом:
1. Список из 12–15 контактов: знакомые организаторы, стендап-клубы и камерные площадки Алматы, организаторы из открытых афиш.
2. Первые 5 приглашений — в первую неделю. Дальше — по ответам и по рекомендациям («кого ещё спросить»).
3. После каждого интервью — заметки по шаблону и столбец «Ответы» в `assumptions.md`.
4. После 3 интервью МСБ — сводка: какие допущения подтвердились. Если базовый сценарий расходится с ответами, финмодель пересчитывается, а в записку идёт честное «было → стало».

## Приглашение

> Здравствуйте! Меня зовут [имя], я пишу дипломный проект о продаже билетов для небольших организаторов. Хочу понять, как вы продаёте билеты сейчас и что в этом неудобно. Займёт 30 минут, звонок или встреча. Я ничего не продаю. Ваши ответы попадут в диплом только обезличенно, если не разрешите иначе. Удобно на этой или следующей неделе?

## Данные

- **В репозиторий — только обезличенное.** Заметки по шаблону, без имён, контактов и названий организаций, если собеседник не разрешил явно.
- **Записи и заполненные согласия — вне репозитория**, у владельца, удаляются после защиты (не позже 30.06.2027).
- **Цитаты в записке и на слайдах** — только из заметок с согласием на цитату.

## Порядок

Демо показывается только в конце разговора и только если собеседник просит: показ продукта в начале превращает интервью в продажу, и ответы становятся вежливыми. Локальный запуск — по корневому README (`docker compose up`).
