# Допущения финмодели → вопрос → что меняет ответ

Какие допущения финмодели (`docs/business/finmodel.xlsx`, лист «Допущения») можно проверить в интервью и насколько ответ сдвигает итог. Итог — операционная прибыль базового сценария за три года: сейчас **−15,0 млн ₸**, окупаемости за три года нет (`docs/business/README.md`, раздел «Результаты»).

Строки отсортированы по тому, насколько сильно допущение двигает итог. Числа — прогон `python3 docs/business/sensitivity.py`: меняется одно допущение, остальные — как в базовом сценарии. Полная таблица — в конце файла.

| Допущение (база) | Вопрос (номер в гайде) | Что меняет ответ: прибыль за 3 года, млн ₸ | Ответы |
|---|---|---|---|
| CAC — 150 000 ₸ на организатора | Как выбрали нынешний способ продажи, кто посоветовал (МСБ 3.2); кого ещё спросить (5.1) | 50 000 ₸ → **+3,0**, окупаемость на 24-м месяце; 300 000 ₸ → **−42,0** | |
| Событий на организатора — 1,2 в месяц | Сколько событий с платными билетами за 12 месяцев (МСБ 1.2) | 2,0 → **+4,0**, окупаемость на 31-м месяце; 0,7 → **−26,8** | |
| Билетов на событие — 110 | Сколько мест в зале и сколько продали на последнем событии (МСБ 2.1) | 160 → **−2,1**; 60 → **−27,9** | |
| Цена билета — 6 000 ₸ | Самый дешёвый, самый дорогой, самый частый билет (МСБ 2.2) | 8 000 ₸ → **−4,4**; 4 000 ₸ → **−25,6** | |
| Отток — 4,5% организаторов в месяц | Меняли ли способ продажи за два года и почему (МСБ 3.4) | 2,5% → **−9,7**; 8% → **−21,5** | |
| Бесплатные билеты — 10% | Сколько было приглашений и гостей (МСБ 2.3) | 0% → **−11,4**; 30% → **−22,1** | |
| Возвраты — 3% | Сколько людей попросили вернуть деньги (МСБ 2.5) | 10% → **−19,2** | |
| Билетов в заказе — 2 | По одному, парами или компаниями (МСБ 2.4) | 3 → **−14,2**; 1,3 → **−16,2** | |
| Новых организаторов — 3 / 5 / 7 в месяц по годам | Кого ещё спросить, можно ли сослаться (МСБ 5.1) | в 1,5 раза больше → **−14,3**; вдвое меньше → **−15,7** | |

## Что из этого следует для интервью

- **Главное — объём на организатора и стоимость привлечения.** Число событий в месяц и билетов на событие организатор знает точно: это первые вопросы гайда. Каждое из них в одиночку сдвигает итог на 12–19 млн ₸, CAC — от +18 до −27 млн ₸.
- **CAC интервью не измерит.** Оно покажет канал: если организаторы выбирают по совету коллег, привлечение дешевле. Сам CAC проверяют первые месяцы продаж.
- **Скорость роста почти не меняет итог за три года.** Организатор окупает своё привлечение примерно за 10 месяцев (лист «Юнит-экономика»), поэтому новые организаторы последнего года до горизонта не окупаются. Если звать в полтора раза больше, итог меняется только на 0,7 млн ₸. Значит, на защите спорить о темпе роста бесполезно, спорить надо о юнит-экономике.

## Что интервью не проверяет

| Допущение (база) | Чем проверить | Что меняет: прибыль за 3 года, млн ₸ |
|---|---|---|
| Эквайринг — 2% от оплаты | Публичные тарифы эквайеров; внутренние данные работодателя не используются (spec.md, «Риски») | 1,2% → **−4,5**; 3% → **−28,1** |
| SMS — 20 ₸ за заказ | Публичные цены SMS-агрегаторов | 0 ₸ → **−12,7**; 40 ₸ → **−17,3** |
| Сбор с покупателя — 5% | Решение владельца (2026-10-02); вопрос МСБ 4.3 показывает только реакцию покупателей | 4% → −26,4; 6% → −3,6; 7% → +7,7 (`docs/business/README.md`, «Чувствительность») |
| Численности рынка — около 1 290 организаторов | Открытые данные и вопрос «кого ещё знаете» (МСБ 5.1); для проверки по-настоящему нужно больше интервью, чем до защиты (лист решений, вопрос 4) | Не влияет на итог базового сценария: он задан числом новых организаторов, а не долей рынка |
| Налог 4% | Консультация юриста по агентской схеме | Без агентской схемы модель не сходится (лист «Риски») |
