# Заметки интервью: шаблон

Заполняется в течение суток после разговора. В репозиторий кладётся только эта обезличенная версия: без имён, телефонов, ссылок на соцсети и названий организаций, если собеседник не разрешил их явно (`consent.md`).

```markdown
## МСБ-1 (или КРУП-1)

- Дата: 2026-11-05
- Тип событий: стендап-вечера
- Город: Алматы
- Зал: 120 мест
- Согласие: цитаты без имени — да; с названием — нет; демо — да

### Числа

| Что | Ответ | Допущение в модели |
|---|---|---|
| Событий с платными билетами за 12 месяцев | | 1,2 в месяц |
| Продано билетов на последнем событии | | 110 |
| Цена: самый дешёвый / самый частый / самый дорогой | | 6 000 ₸ |
| Бесплатных мест на последнем событии | | 10% |
| Покупали по одному / парами / компаниями | | 2 билета в заказе |
| Возвратов на последнем событии | | 3% |
| Где продаёт сейчас, сколько это стоит, кто платит | | сбор 5% с покупателя |
| Как выбрал нынешний способ продажи | | CAC 150 000 ₸ |
| Менял ли способ продажи за два года и почему | | отток 4,5% в месяц |

### Цитаты

Только с согласия, дословно.

### Что удивило

То, чего нет в модели и гайде.

### Что меняется

Какие строки `assumptions.md` подтвердились, какие нет.

### Следующий шаг

Кого посоветовал, можно ли вернуться с демо.
```
