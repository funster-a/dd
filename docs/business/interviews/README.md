# Интервью с организаторами

**Владелец решил (2026-10-09): до защиты интервью не проводятся.** Набор остаётся для проверки допущений финмодели после запуска.

Финмодель держится на допущениях (`docs/business/README.md`), а реальных клиентов у проекта нет. Интервью нужны, чтобы сверить допущения с опытом настоящих организаторов. Цель — проверить допущения, не продавать.

## Что здесь

| Файл | Зачем |
|---|---|
| [`guide-smb.md`](guide-smb.md) | Гайд для организатора МСБ: 30–40 минут, вопросы о последнем событии и нынешнем способе продажи |
| [`guide-large.md`](guide-large.md) | Гайд для промоутера или площадки от 2 000 мест: старт продаж, выбор оператора, условия |
| [`assumptions.md`](assumptions.md) | Какое допущение финмодели проверяет какой вопрос и насколько ответ меняет итог |

| [`notes-template.md`](notes-template.md) | Шаблон обезличенных заметок |

## Сколько и когда

**До защиты — ни одного интервью** (`docs/defense/decisions.md`, вопрос 4, вариант В). Допущения финмодели опираются на публичные источники, а какие из них решают итог, показывает [`assumptions.md`](assumptions.md).

После запуска (июнь 2027), по умолчанию: 3–5 организаторов МСБ из первых клиентов и 1–2 промоутера или площадки на первых переговорах о крупном событии. Ответы сверяются с данными продаж первых месяцев.

Шаги:
1. Список контактов: первые клиенты, организаторы из открытых афиш, промоутеры и площадки, с которыми идут переговоры.
2. Приглашения — по ответам и по рекомендациям («кого ещё спросить»).
3. После каждого интервью — заметки по шаблону и столбец «Ответы» в `assumptions.md`.
4. После 3 интервью МСБ — сводка: какие допущения подтвердились. Если базовый сценарий расходится с ответами или с данными продаж, финмодель пересчитывается с честным «было → стало».

Приглашение, согласие и гайды написаны под дипломный проект. Перед первым интервью после запуска их надо переписать, а срок хранения записей — пересмотреть.

## Приглашение

> Здравствуйте! Меня зовут [имя], я пишу дипломный проект о продаже билетов для небольших организаторов. Хочу понять, как вы продаёте билеты сейчас и что в этом неудобно. Займёт 30 минут, звонок или встреча. Я ничего не продаю. Ваши ответы попадут в диплом только обезличенно, если не разрешите иначе. Удобно на этой или следующей неделе?

## Данные

- **В репозиторий — только обезличенное.** Заметки по шаблону, без имён, контактов и названий организаций, если собеседник не разрешил явно.
- **Записи и заполненные согласия — вне репозитория**, у владельца, удаляются по сроку, который задаётся при переписывании согласия перед первым интервью (см. выше).
- **Цитаты в материалах проекта** — только из заметок с согласием на цитату.

## Порядок

Демо показывается только в конце разговора и только если собеседник просит: показ продукта в начале превращает интервью в продажу, и ответы становятся вежливыми. Локальный запуск — по корневому README (`docker compose up`).
