# ADR 009. Хранилище файлов

Статус: принято, 2026-09-28

## Контекст

У события есть обложка (до 5 МБ) и необязательная видеообложка (до 15 МБ, spec.md), позже появятся PDF-билеты. Файлы не должны храниться в PostgreSQL и не должны проходить через api: загрузка 15 МБ через сервер занимает соединение и память, а во время старта продаж это недопустимо.

## Решение

1. **S3-совместимое хранилище.** В базе хранится только ключ файла, сам файл лежит в бакете `dd-media`.
2. **Загрузка напрямую из браузера по одноразовой ссылке**, в два шага:
   - `POST /events/{id}/media/uploads` — каталог проверяет вид файла, тип и размер и выдаёт подписанную ссылку `PUT` на 15 минут с ключом вида `organizers/{org}/events/{event}/{kind}/{random}.{ext}`;
   - `PUT /events/{id}/media` — каталог спрашивает у хранилища, что файл действительно загружен, его тип и размер в пределах правил и ключ выдан для этого события, и только тогда прикрепляет его.
   Подписанная ссылка сама по себе не ограничивает тип и размер, поэтому проверка при прикреплении обязательна.
3. **Обложки публичные.** Бакет открыт на чтение без подписи, запись — только по ключам доступа. Обложку отдаёт хранилище (в эксплуатации — через CDN), api в этом не участвует.
4. **Два адреса хранилища.** `S3_ENDPOINT` используется api внутри сети, `S3_PUBLIC_ENDPOINT` — для браузера. Ссылки подписываются публичным адресом, иначе подпись не совпадёт с хостом, на который реально загружает браузер.
5. **Каталог не зависит от хранилища.** Интерфейс `ObjectStore` объявлен в каталоге (правило модулей из `CLAUDE.md`), реализация — `internal/platform/storage`, связывает их `cmd/api`.
6. **Клиент — `minio-go`** (Apache 2.0). Это клиент протокола S3, он работает с любым S3-сервером.
7. **Локальный сервер — SeaweedFS** (Apache 2.0, режим `weed mini`): бакет создаётся при старте, ключи и правило анонимного чтения задаются конфигом из `docker-compose.yml`.

## Альтернативы

- **MinIO как локальный сервер.** Был первым кандидатом, но в 2025 году MinIO свернула распространение образов community-версии. Образ в 2026 году недоступен в зеркалах, а `quay.io` закрыт в окружении разработки. Строить проект на продукте с такой политикой рискованно. Отклонено.
- **Garage.** Тоже S3 и тоже открытый, но требует многошаговой настройки: раскладка кластера, создание ключей через CLI. Для локального запуска сложнее. Отклонено.
- **AWS SDK v2.** Официальный клиент, но заметно тяжелее по зависимостям, чем `minio-go`, при одинаковом нужном нам наборе операций. Отклонено.
- **Загрузка через api.** Проще в реализации, но нагружает сервер ровно там, где важна производительность. Отклонено.
- **Хранить файлы в PostgreSQL (bytea).** Раздувает базу и резервные копии, файл нельзя отдать через CDN. Отклонено.

## Следствия

- В эксплуатации подойдёт любой облачный S3; меняются только переменные `S3_*`.
- SeaweedFS по умолчанию разрешает CORS для любых источников. Для эксплуатации список источников нужно ограничить доменом фронтенда.
- Загруженный, но не прикреплённый файл остаётся в бакете. Очистку таких файлов по сроку добавим фоновой задачей или правилом жизненного цикла бакета.
- Конвертация GIF в видео не входит в MVP: принимаются только MP4 и WebM.
